# План MVP

## Версия 1

- Современная главная страница.
- Каталог товаров из прайса.
- Поиск по коду, названию и исходной группе.
- Фильтры по разделам и цене.
- Заявка на подбор детали.
- Контакты и режим работы магазинов.

## Версия 2

- Backend.
- Админ-панель.
- Загрузка Excel-прайса через браузер.
- Редактирование карточек товаров.
- Загрузка фотографий.
- Управление публикацией товаров.

## Версия 3

- Остатки по магазинам.
- История обновлений прайса.
- Интеграция с 1С.
- Расширенная SEO-структура под категории и модели авто.
