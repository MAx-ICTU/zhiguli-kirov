# Жигули - каталог автозапчастей

Прототип нового сайта-каталога для магазина автозапчастей ВАЗ и LADA в Кирове.

## Что входит

- Главная страница с поиском по каталогу.
- Каталог на основе текущего прайса.
- Фильтры по разделу и цене.
- Карточки товаров с кодом, названием, группой и ценой.
- Форма подбора детали.
- Контакты двух магазинов.
- Админ-панель для каталога и входящих заявок.

## Запуск

```bash
python -m http.server 4173
```

После запуска сайт доступен по адресу:

```text
http://localhost:4173
```

## Админка с backend

```bash
npm run admin
```

Этот режим открывает сайт и API рабочего кабинета:

```text
http://localhost:4173/admin.html
```

## Данные

Товары загружаются из `src/products.js`. В первой версии каталог собран из прайса `price.xls`: 9 427 товарных позиций.
